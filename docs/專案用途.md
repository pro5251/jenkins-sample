實作企業購物網站與透過 Jenkins CI/CD 進行的上版流程,並從中了解整個過程加以學習, 需要實作的環境如下，請參考官網連結實作與配置:

1. 部署的專案架構為前後端分離
1-1. 前端用 Vue3 + tailwindcss v4.*+ primevue v4.* + pinia
1-2. 後端用 C# .NET10 WEBAPI
1-3. 資料庫用 MSSql

2. 實作一個建立一個簡易的購物網站 (RWD), 有前後台功能, 能上架商品、客戶註冊、銷售商品、加入購物車、結帳 (貨到付款)

3.使用 GitLab 來進行程式碼的版控與進行 Jenkins CI/CD
