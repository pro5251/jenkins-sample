# 修正前端 SPA 路由 404 問題

## 問題摘要

訪問 `http://localhost:3000/login` 出現 404 Not Found。

## 原因分析

前端為 SPA（Single Page Application），路由由瀏覽器端 JavaScript 管理。  
nginx 直接接收到 `/login` 請求時，嘗試尋找實體檔案但不存在，因此回傳 404。

## 執行操作

1. **新增** `frontend/nginx.conf`：設定 `try_files` fallback 到 `index.html`
2. **修改** `frontend/Dockerfile`：將 `nginx.conf` 複製到容器內

### nginx.conf 關鍵設定
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```
