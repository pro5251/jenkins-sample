# 修正 docker-compose.yml 路徑錯誤

## 問題摘要

執行 `docker/docker-compose.yml` 時出現錯誤：
```
unable to prepare context: path "/mnt/d/github/jenkins-sample/docker/backend" not found
```

## 原因分析

`docker/docker-compose.yml` 中 `backend` 與 `frontend` 服務的 `build.context` 設定為：
- `./backend` → 解析為 `docker/backend`（不存在）
- `./frontend` → 解析為 `docker/frontend`（不存在）

但實際的 `backend` 與 `frontend` 目錄位於專案根目錄，不在 `docker/` 資料夾內。

## 執行操作

修改 `docker/docker-compose.yml`，將相對路徑改為往上一層：

| 服務 | 修改前 | 修改後 |
|------|--------|--------|
| backend | `context: ./backend` | `context: ../backend` |
| frontend | `context: ./frontend` | `context: ../frontend` |

## 產出檔案

- `docker/docker-compose.yml`（已修改）
