# 修正容器內 casc/jenkins.yaml 是空的問題

## 問題摘要
Docker 容器內的 `casc/jenkins.yaml` 是空的，導致 Job 未出現

## 根本原因

1. 之前移除了 bind mount (`./jenkins/jenkins.yaml:/var/jenkins_home/casc/jenkins.yaml:ro`)
2. 改為用 Dockerfile `COPY` 打包進映像
3. 但映像沒有重新 build，舊容器的 ENV 仍指向 `/var/jenkins_home/casc/jenkins.yaml`
4. 該路徑在 named volume 中存在但為空（舊 bind mount 移除後的遺留空檔）

## 修正方式

在 `ci-cd-docker-compose.yml` 加回 bind mount，直接掛載到與 `CASC_JENKINS_CONFIG` 相同的路徑：

```yaml
- ./jenkins/jenkins.yaml:/usr/share/jenkins/casc/jenkins.yaml:ro
```

## 三處路徑統一

| 位置 | 路徑 |
|------|------|
| Dockerfile COPY | `/usr/share/jenkins/casc/jenkins.yaml` |
| docker-compose bind mount | `/usr/share/jenkins/casc/jenkins.yaml` |
| CASC_JENKINS_CONFIG ENV | `/usr/share/jenkins/casc/jenkins.yaml` |

## 優點
- 修改 `jenkins.yaml` 不需重新 build 映像
- 容器重啟即套用新設定

## 產出檔案
- 修改：`docker/ci-cd-docker-compose.yml`
