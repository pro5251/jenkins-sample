# 解釋 docker-compose 各參數用途

## 問題摘要
用繁體中文解釋 `docker/ci-cd-docker-compose.yml` 中各個參數的用途

## 回答重點

### 頂層設定
- `version: '3.8'`：Docker Compose 檔案格式版本

### GitLab 服務
- `image`：使用 GitLab 社群版最新映像
- `container_name`：固定容器名稱方便辨識
- `restart: always`：自動重啟策略
- `GITLAB_OMNIBUS_CONFIG`：GitLab 內部設定注入
- `external_url`：GitLab 對外 URL，影響 clone 網址
- `gitlab_shell_ssh_port`：SSH clone 顯示的埠號
- ports `8929:8929`：HTTP Web UI
- ports `2224:22`：SSH Git 操作
- volumes：Named Volume 保存設定/日誌/資料

### Jenkins 服務
- `build context`：從 Dockerfile 自行建置映像
- ports `8080:8080`：Web UI
- ports `50000:50000`：Master ↔ Agent 通訊
- `docker.sock` 掛載：讓 Jenkins 操控主機 Docker
- `jenkins.yaml:ro`：JCasC 設定檔唯讀掛載
- `JAVA_OPTS`：跳過 Setup Wizard
- `CASC_JENKINS_CONFIG`：指定 JCasC 設定檔路徑
- `depends_on`：啟動順序控制

### Networks
- `cicd-network`：自訂橋接網路，支援容器名稱 DNS 解析
- `driver: bridge`：Docker 橋接網路模式

### Volumes
- Named Volume 由 Docker 管理，容器刪除後資料保留

## 產出檔案
無（純說明，未修改任何檔案）
