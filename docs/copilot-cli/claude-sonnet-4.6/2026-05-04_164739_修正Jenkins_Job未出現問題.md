# 修正 Jenkins Job 未出現在網站的問題

## 問題摘要
Jenkins 網站有出現系統訊息，但看不到 Job

## 根本原因

Job DSL `script` 區塊預設受 **Script Security** 沙盒保護。  
JCasC 嘗試執行 Job DSL groovy script 建立 Job 時被擋下，需要管理員手動 approve 才能執行，但在自動化部署中無法手動操作。

## 修正方式

在 `jenkins.yaml` 加入：
```yaml
security:
  globalJobDslSecurityConfiguration:
    useScriptSecurity: false
```

## 重新部署指令

```bash
cd docker
docker compose -f ci-cd-docker-compose.yml down
docker compose -f ci-cd-docker-compose.yml build jenkins
docker compose -f ci-cd-docker-compose.yml up -d
```

- 修改：`docker/jenkins/jenkins.yaml`
