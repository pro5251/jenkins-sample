# 修正 jenkins-expert Skill 安裝目錄

## 問題摘要

前次安裝路徑錯誤（`~/.copilot/skills/jenkins-expert.md`），正確結構應為資料夾 `~/.copilot/skills/jenkins-expert/SKILL.md`，與其他 skill（`docker-troubleshoot/`、`git-commit-helper/`）一致。

## 回答重點

- GitHub Copilot CLI 的 Skill 結構：`~/.copilot/skills/{skill-name}/SKILL.md`
- 舊錯誤路徑：`~/.copilot/skills/jenkins-expert.md`（單一檔案）
- 正確路徑：`~/.copilot/skills/jenkins-expert/SKILL.md`（資料夾內）

## 執行的操作

1. 刪除舊版錯誤檔案：`rm ~/.copilot/skills/jenkins-expert.md`
2. 建立正確目錄：`mkdir -p ~/.copilot/skills/jenkins-expert`
3. 複製 SKILL.md：`cp jenkins-expert/SKILL.md ~/.copilot/skills/jenkins-expert/SKILL.md`
4. 建立安裝腳本：`jenkins-expert/install.sh`，確保日後重裝路徑正確

## 產出的檔案

| 檔案 | 說明 |
|---|---|
| `~/.copilot/skills/jenkins-expert/SKILL.md` | 已安裝的 Skill（正確位置） |
| `jenkins-expert/install.sh` | 日後重新安裝用的腳本 |

## 日後安裝方式

```bash
./jenkins-expert/install.sh
```
