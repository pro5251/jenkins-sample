# 將所有 Vue 元件重構為 Tailwind CSS

## 問題摘要

前端 CSS 未正確渲染，原因是所有 Vue 元件使用自定義 class（如 `.login`、`.cart-item`）但沒有對應的 CSS 樣式定義。

## 執行操作

將 18 個 Vue 元件的自定義 class 全部改為 Tailwind CSS utility classes，並移除 `<style>` 區塊。

## 設計規範

- **主色**: `bg-blue-600` / `text-blue-600`
- **導覽列**: `bg-gray-900` 深色背景
- **卡片**: `bg-white rounded-lg shadow-md`
- **按鈕**: `bg-blue-600 hover:bg-blue-700 text-white px-4 py-2 rounded`
- **表單欄位**: `border border-gray-300 rounded focus:ring-2 focus:ring-blue-500`
- **Admin 側邊欄**: `w-64 bg-gray-800 text-white`
- **商品格狀**: 響應式 `grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4`
