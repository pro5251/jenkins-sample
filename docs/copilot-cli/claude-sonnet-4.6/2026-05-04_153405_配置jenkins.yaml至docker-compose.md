# 配置 jenkins.yaml 至 docker-compose

## 問題摘要
將 `docker/jenkins/jenkins.yaml` 配置進 `docker/ci-cd-docker-compose.yml`

## 回答重點
`jenkins.yaml` 已透過 volume 掛載（`./jenkins/jenkins.yaml:/var/jenkins_home/casc/jenkins.yaml:ro`），但缺少環境變數 `CASC_JENKINS_CONFIG`，導致 Jenkins Configuration as Code (JCasC) 插件無法知道設定檔的位置。

## 執行操作
在 `docker/ci-cd-docker-compose.yml` 的 jenkins service `environment` 區塊新增：
```yaml
- CASC_JENKINS_CONFIG=/var/jenkins_home/casc/jenkins.yaml
```

## 修改前後對比
**修改前：**
```yaml
environment:
  - JAVA_OPTS=-Djenkins.install.runSetupWizard=false
```

**修改後：**
```yaml
environment:
  - JAVA_OPTS=-Djenkins.install.runSetupWizard=false
  - CASC_JENKINS_CONFIG=/var/jenkins_home/casc/jenkins.yaml
```

## 產出檔案
- 修改：`docker/ci-cd-docker-compose.yml`
