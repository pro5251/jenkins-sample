# 確認 JCasC 設定檔放置路徑

## 問題摘要
確認 JCasC 設定檔是否應放在 `/usr/share/jenkins/casc/` 中

## 回答重點

### 結論：不是固定路徑，由 CASC_JENKINS_CONFIG 決定

根據官方文件（https://github.com/jenkinsci/configuration-as-code-plugin），JCasC 讀取路徑由 `CASC_JENKINS_CONFIG` 環境變數決定，可指向：
- 資料夾：`/var/jenkins_home/casc_configs`
- 單一檔案：`/var/jenkins_home/casc_configs/jenkins.yaml`

### 目前配置流程

1. `Dockerfile COPY jenkins.yaml → /usr/share/jenkins/ref/casc/jenkins.yaml`（映像種子機制）
2. Jenkins 啟動時自動將 `ref/` 內容複製到 `jenkins_home`
3. `CASC_JENKINS_CONFIG=/var/jenkins_home/casc/jenkins.yaml` 讀取此路徑

### 重要區分

| 路徑 | 用途 |
|------|------|
| `/usr/share/jenkins/ref/` | Jenkins Docker 種子機制，用來初始化 jenkins_home |
| `/var/jenkins_home/casc/` | JCasC 實際讀取的位置（由 CASC_JENKINS_CONFIG 指定） |

目前配置正確，無需修改。
