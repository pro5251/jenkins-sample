# 修正 JCasC 設定檔路徑不一致問題

## 問題摘要
調整修正 Jenkins 部署配置，確保 Jenkins 網站部署後能正確套用 JCasC 設定

## 問題發現

Dockerfile 中路徑不一致：
- COPY 目標：`/usr/share/jenkins/casc/jenkins.yaml`
- CASC_JENKINS_CONFIG：`/var/jenkins_home/casc/jenkins.yaml`

兩者不同，導致 Jenkins 無法讀取設定檔。

## 修正方式

將 `CASC_JENKINS_CONFIG` 直接指向映像內的路徑，不依賴 ref 複製機制：

```dockerfile
COPY --chown=jenkins:jenkins jenkins.yaml /usr/share/jenkins/casc/jenkins.yaml
ENV CASC_JENKINS_CONFIG=/usr/share/jenkins/casc/jenkins.yaml
```

## 部署後 Jenkins 網站出現的內容

| 項目 | 設定值 |
|------|--------|
| 系統訊息 | `Jenkins - Shopping Website CI/CD` |
| 管理員帳號 | `admin / admin` |
| Pipeline Job | `jenkins-sample` |
