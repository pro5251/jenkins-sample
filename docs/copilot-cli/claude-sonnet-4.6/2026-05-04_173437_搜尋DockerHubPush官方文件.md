# 搜尋 Docker Hub Push 官方文件

## 問題摘要

使用者要求搜尋 Docker Hub Push 有哪些官方文件可參考。

---

## 官方文件清單

### 1. Jenkins Pipeline + Docker 官方文件
- **URL**: https://www.jenkins.io/doc/book/pipeline/docker/
- **說明**: Jenkins 官方最完整的 Pipeline + Docker 整合文件，涵蓋 Build、Push、Registry 認證完整流程
- **重點**: `docker.withRegistry()` DSL 是官方推薦的 Push 寫法

### 2. Docker Workflow Plugin 文件
- **URL**: https://github.com/jenkinsci/docker-workflow-plugin/blob/master/docs/docker-workflow.md
- **說明**: Docker Workflow Plugin 完整 DSL 文件，提供 `docker.build`、`push`、`withRegistry`、`withServer` 等方法說明

### 3. Docker 官方 CLI Push 文件
- **URL**: https://docs.docker.com/reference/cli/docker/image/push/
- **說明**: `docker push` 指令底層參考，對應 Jenkinsfile 中 `sh 'docker push ...'` 的寫法

---

## 兩種推送寫法比較

### 方法一：Docker Pipeline DSL（官方推薦）
```groovy
docker.withRegistry('https://registry.hub.docker.com', 'dockerhub-credentials') {
    def image = docker.build("mycorp/myapp:${env.BUILD_TAG}")
    image.push()           // 推送 build tag
    image.push('latest')   // 同時更新 latest
}
```
- 優點：自動處理 login/logout，語意清晰，官方最佳實踐
- 缺點：不直接搭配 `docker compose push`

### 方法二：Shell 指令（目前專案使用）
```groovy
withCredentials([usernamePassword(credentialsId: 'dockerhub-credentials', ...)]) {
    sh 'echo "$DOCKER_PASS" | docker login -u "$DOCKER_USER" --password-stdin'
    sh "docker compose push"
    sh 'docker logout'
}
```
- 優點：與 Docker Compose 整合更彈性
- 缺點：需手動管理 login/logout

---

## 建議改進

可將目前的 Shell 寫法改為 Docker Pipeline DSL 寫法：

```groovy
stage('Docker Push') {
    when { branch 'main' }
    steps {
        script {
            docker.withRegistry('https://registry.hub.docker.com', 'dockerhub-credentials') {
                docker.image("${DOCKER_USER}/jenkins-sample-backend:${IMAGE_TAG}").push()
                docker.image("${DOCKER_USER}/jenkins-sample-frontend:${IMAGE_TAG}").push()
            }
        }
    }
}
```
