# 修正問答記錄路徑錯誤並更新 AGENTS.md

## 問題摘要
`docs/opencode/claude-sonnet-4.6/` 中的文檔應歸類在 `docs/copilot-cli/claude-sonnet-4.6/`，確認原因並修正對應的 SKILL（`AGENTS.md`）

## 根本原因

`AGENTS.md` 是 **opencode** 與 **GitHub Copilot CLI** 共用的指令檔。原始路徑 `docs/opencode/{model_name}/` 是為 opencode 工具設計的，但 Copilot CLI 也讀取此檔案，導致誤將 Copilot CLI 的問答記錄存到 `docs/opencode/` 而非 `docs/copilot-cli/`。

## 執行操作

### 1. 修正 `AGENTS.md`
將記錄路徑區分兩個工具：
- GitHub Copilot CLI：`docs/copilot-cli/{model_name}/...`
- OpenCode：`docs/opencode/{model_name}/...`

### 2. 移動已建立的檔案
將 10 個檔案從 `docs/opencode/claude-sonnet-4.6/` 移動至 `docs/copilot-cli/claude-sonnet-4.6/`，並刪除空目錄。

## 產出檔案
- 修改：`AGENTS.md`
- 移動：`docs/opencode/claude-sonnet-4.6/*` → `docs/copilot-cli/claude-sonnet-4.6/*`
