# 配置 Jenkins CI/CD 資源

## 問題摘要
使用者希望從 `docker/jenkins/` 配置 CI/CD 所需的 Jenkins Job 等資源，並依據官方 Jenkins Docker 文件進行正確設定。

## 分析發現的問題

| 問題 | 說明 |
|---|---|
| 使用舊版映像 | `jenkins/jenkins:lts` 未指定 JDK 版本 |
| 缺少關鍵插件 | 缺少 `gitlab-plugin`、`docker-workflow`、`credentials-binding` 等 |
| Job 指向錯誤來源 | `jenkins.yaml` Job 指向 GitHub，但架構是本地 GitLab |
| 缺少 GitLab 伺服器設定 | JCasC 未設定 GitLab Connection |
| 憑證寫死 | 沒有透過環境變數管理敏感資訊 |
| Jenkinsfile 不完整 | 缺少平行建置、逾時保護、GitLab 狀態回報、Workspace 清理 |
| 無 `.env` 範本 | 無環境變數範本供開發者參考 |

## 執行的操作

### 1. 更新 `docker/jenkins/Dockerfile`
- 升級至 `jenkins/jenkins:lts-jdk21`（官方建議）
- 新增 `usermod -aG docker jenkins`（docker group 方式，優於純 sudo）
- 新增插件：`gitlab-plugin`、`docker-workflow`、`credentials-binding`、`ssh-credentials`、`build-timeout`、`timestamper`、`ws-cleanup`、`ansicolor`
- 每個 `apt-get` 後立即清除快取，減少映像大小

### 2. 更新 `docker/jenkins/jenkins.yaml`（JCasC）
- **管理員密碼** 改為 `${JENKINS_ADMIN_PASSWORD:-admin}` 環境變數注入
- **新增 GitLab 伺服器連線**（`unclassified.gitLabConnectionConfig`）
  - URL: `http://gitlab:8929`（Docker 內部網路 hostname）
- **新增三組憑證**（全部透過環境變數注入）：
  - `gitlab-credentials`：Git Clone 使用（usernamePassword）
  - `gitlab-api-token`：Webhook 狀態回報使用（string）
  - `dockerhub-credentials`：推送 Docker 映像使用（usernamePassword）
- **更新 Job DSL**：
  - 綁定 GitLab Connection
  - Git Clone URL 改為 `http://gitlab:8929/root/jenkins-sample.git`
  - 加入 GitLab Push/MR Webhook 觸發 + SCM 輪詢備援

### 3. 更新 `jenkins/Jenkinsfile`
- 新增 `options`：30 分鐘逾時、timestamps、ansiColor、logRotator
- **平行化建置**：Backend + Frontend 同時執行
- **平行化測試**：Backend + Frontend 同時執行
- `dotnet test` 輸出 `.trx` 測試報告
- `npm install` 改為 `npm ci`（CI 環境最佳實踐）
- `Deploy` 加入 `when { branch 'main' }` 保護
- `post` 新增 GitLab Commit Status 回報（running / success / failed）
- `post.always` 加入 `cleanWs()` 清理 Workspace

### 4. 更新 `docker/ci-cd-docker-compose.yml`
- 新增所有環境變數配置（透過 `${VAR:-default}` 語法）
- 新增詳細繁體中文註解

### 5. 新增 `docker/.env.example`
- 提供環境變數範本，說明每個變數的用途與取得方式

### 6. 新增根目錄 `.gitignore`
- 確保 `docker/.env` 不被提交至版控系統

## 啟動方式

```bash
# 1. 建立環境變數檔案
cp docker/.env.example docker/.env
# 2. 編輯 .env 填入實際值
# 3. 啟動 GitLab + Jenkins
cd docker
docker compose -f ci-cd-docker-compose.yml --env-file .env up -d
# 4. 等待 GitLab 初始化（約 3-5 分鐘）
# 5. 訪問 Jenkins: http://localhost:8080（帳號: admin，密碼: .env 中設定）
# 6. 訪問 GitLab: http://localhost:8929
```

## GitLab Webhook 設定步驟（啟動後）
1. 在 GitLab 建立 `jenkins-sample` 專案
2. 取得 GitLab API Token：User Settings → Access Tokens
3. 填入 `docker/.env` 的 `GITLAB_API_TOKEN`
4. 重啟 Jenkins 容器使設定生效
5. 在 GitLab 專案 Settings → Webhooks 新增：
   - URL: `http://jenkins:8080/project/jenkins-sample`
   - 勾選 Push events、Merge request events
