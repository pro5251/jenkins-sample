# 將 jenkins.yaml 改為透過 jenkins_home 統一掛載

## 問題摘要
應將 `jenkins.yaml` 放入 `jenkins_home` 統一掛載，而非使用獨立的 bind mount

## 修改方式

### Dockerfile
新增 `COPY` 指令，將 `jenkins.yaml` 複製到 `/usr/share/jenkins/ref/casc/jenkins.yaml`。  
Jenkins 啟動時會自動將 `/usr/share/jenkins/ref/` 的檔案同步至 `jenkins_home`（`/var/jenkins_home/`）。

```dockerfile
COPY --chown=jenkins:jenkins jenkins.yaml /usr/share/jenkins/ref/casc/jenkins.yaml
```

### docker-compose.yml
移除獨立的 bind mount：
```yaml
# 移除此行
- ./jenkins/jenkins.yaml:/var/jenkins_home/casc/jenkins.yaml:ro
```

## 架構說明
| 機制 | 說明 |
|------|------|
| `COPY` → `/usr/share/jenkins/ref/casc/` | 建置映像時將 yaml 打包進去 |
| Jenkins 啟動機制 | 自動將 ref/ 內容複製到 jenkins_home |
| `jenkins_home` named volume | 統一管理所有 Jenkins 資料 |

## 產出檔案
- 修改：`docker/jenkins/Dockerfile`
- 修改：`docker/ci-cd-docker-compose.yml`
