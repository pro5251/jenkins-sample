# 建立 Jenkins Skill 與記憶管理

**日期**: 2026-05-10  
**模型**: claude-sonnet-4-6

---

## 問題摘要

1. 評估是否能透過 API 控制 Jenkins Job 啟動
2. 建立 Jenkins Skill 以控制 Job 執行
3. 確認 Skill 的正確結構規範
4. 建立並整理 Agent 記憶系統

---

## 回答重點

### Jenkins API 可行性
- Jenkins 提供完整 REST API，支援觸發 Job、查詢狀態、取得 Console Output
- 認證方式：API Token（建議）或帳號密碼
- 需先取得 CSRF Crumb 才能呼叫 POST API

### Skill 正確結構（被使用者指正）
- 錯誤做法：單一 `skills/jenkins.md`
- 正確做法：目錄結構 `.claude/skills/jenkins/SKILL.md` + YAML frontmatter
- 規範來源：https://code.claude.com/docs/en/skills

### 記憶系統位置
- 統一存放於 `/home/node/workspace/.claude/memory/`
- 原因：workspace 持久化到主機，`.claude/` 符合 Claude Code 慣例

### Discord Reply 調查
- docs 中無相關設定，reply 引用內容未傳入是 OpenAB adapter 層問題

---

## 執行的操作

1. 建立 `docker/docker-compose.jenkins-only.yml`（僅啟動 Jenkins，不需 GitLab）
2. 建立 `docker/jenkins/jenkins-standalone.yaml`（含 hello-world Job 的 JCasC 設定）
3. 建立 `.claude/skills/jenkins/SKILL.md`（正確 Skill 結構）
4. 建立 `.claude/skills/jenkins/config.env`（Jenkins 連線設定）
5. 建立 `.claude/memory/` 下的記憶檔案群
