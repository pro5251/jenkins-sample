## 執行的操作
1. 檢查前置鉤子配置 (`before_plan`: `speckit.git.commit`, optional: true)
2. 執行 `.specify/scripts/powershell/setup-plan.ps1 -Json`
   - FEATURE_SPEC: `D:\jenkins-sample\specs\001-shopping-website-cicd\spec.md`
   - IMPL_PLAN: `D:\jenkins-sample\specs\001-shopping-website-cicd\plan.md`
   - SPECS_DIR: `D:\jenkins-sample\specs\001-shopping-website-cicd`
   - BRANCH: `001-shopping-website-cicd`
3. 讀取 `.specify/memory/constitution.md` 與 `specs/001-shopping-website-cicd/plan.md` (模板)
4. **Phase 0**: 生成 `research.md`
   - Decision 1: 前端技術選型 (Vue 3 + Tailwind CSS v4.* + PrimeVue v4.* + Pinia)
   - Decision 2: 後端技術選型 (C# .NET 10 Web API)
   - Decision 3: 資料庫選型 (MSSQL + Entity Framework Core)
   - Decision 4: 容器化與編排 (Docker + Docker Compose)
   - Decision 5: CI/CD 工具選型 (Jenkins + GitLab)
   - Decision 6: 測試框架選型 (Vitest + xUnit + Docker Compose)
5. **Phase 1**: 生成 `data-model.md`
   - User (用戶): 8 個屬性，驗證規則，狀態轉換
   - Product (商品): 9 個屬性，驗證規則
   - Order (訂單): 9 個屬性，狀態轉換 (pending→confirmed→shipped→delivered)
   - OrderItem (訂單項目): 6 個屬性
   - Cart (購物車): 6 個屬性
   - 實體關聯圖、資料庫限制、索引策略、初始資料
6. **Phase 1**: 生成 `contracts/` API 合約
   - `auth-api.md`: 認證 API (register, login, logout, me)
   - `products-api.md`: 商品 API (列表、詳情、分類、新增、更新、刪除)
   - `cart-api.md`: 購物車 API (查看、新增、更新、刪除、清空)
   - `orders-api.md`: 訂單 API (結帳、列表、詳情、更新狀態)
7. **Phase 1**: 生成 `quickstart.md`
   - 前置需求、本地開發設定、專案結構、關鍵命令、API 測試、Jenkins CI/CD 快速開始、常見問題
8. 填充 `plan.md`
   - Summary: 專案概述
   - Technical Context: 語言版本、依賴、儲存、測試、平台、類型、效能目標、限制、規模
   - Constitution Check: 5 個原則檢查 (全部通過 ✅)
   - Project Structure: Documentation 與 Source Code 結構
9. 更新 `AGENTS.md`
   - 在 `<!-- SPECKIT START -->` 與 `<!-- SPECKIT END -->` 之間更新 plan 引用
   - 新路徑: `specs/001-shopping-website-cicd/plan.md`
10. 檢查後置鉤子 (`after_plan`: `speckit.git.commit`, optional: true)
11. 生成本摘要文件
