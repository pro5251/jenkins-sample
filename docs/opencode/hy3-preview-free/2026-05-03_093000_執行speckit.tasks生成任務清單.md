# 執行 /speckit.tasks 生成任務清單

## 問題摘要
用戶輸入空白，系統觸發 `/speckit.tasks` 命令，要求根據 spec.md、plan.md、data-model.md、contracts/ 生成任務清單。

## 回答重點
- 執行前置鉤子 `before_tasks` (speckit.git.commit, optional: true)
- 執行 `setup-tasks.ps1 -Json` 取得路徑資訊
- 讀取 plan.md、spec.md、tasks-template.md
- 根據 4 個 User Stories (P1, P2) 生成任務清單
- 總共生成 104 個任務，組織成 7 個 Phase
- 任務遵循嚴格格式：`[ID] [P?] [Story] Description with file path`

## 執行的操作
1. 檢查前置鉤子配置 (`before_tasks`: `speckit.git.commit`, optional: true)
2. 執行 `.specify/scripts/powershell/setup-tasks.ps1 -Json`
   - FEATURE_DIR: `D:\jenkins-sample\specs\001-shopping-website-cicd`
   - AVAILABLE_DOCS: research.md, data-model.md, contracts/, quickstart.md
   - TASKS_TEMPLATE: `.specify\templates\tasks-template.md`
3. 讀取 `plan.md` (技術堆疊、程式庫、專案結構)
4. 讀取 `spec.md` (4 個 User Stories 與優先級 P1, P2)
5. 讀取 `tasks-template.md` 作為任務格式基礎
6. **Phase 1: Setup** (11 任務)
   - T001-T011: 專案結構、.NET 初始化、Vue 初始化、Docker 配置、Jenkinsfile
7. **Phase 2: Foundational** (11 任務)
   - T012-T022: SQL Server、Entity Framework、認證中介軟體、基礎模型、CORS、環境配置
8. **Phase 3: User Story 1** (26 任務, P1, MVP)
   - T023-T051: 基礎架構、後端模型/控制器/服務、前端組件/頁面/狀態管理
9. **Phase 4: User Story 2** (20 任務, P2)
   - T052-T071: 前台功能 (註冊、登入、商品瀏覽、購物車、結帳)
10. **Phase 5: User Story 3** (11 任務, P2)
    - T072-T084: 後台管理 (商品、訂單、會員管理)
11. **Phase 6: User Story 4** (9 任務, P1)
    - T085-T095: Jenkins CI/CD 流程 (GitLab 整合、Pipeline、Docker 建置、部署)
12. **Phase 7: Polish** (9 任務)
    - T096-T104: 文件更新、程式碼重構、效能優化、安全性強化
13. 生成 `tasks.md` 並包含所有任務、依賴關係、並行範例、實作策略
14. 檢查後置鉤子 (`after_tasks`: `speckit.git.commit`, optional: true)
15. 生成此摘要檔案

## 產出的檔案

## 依賴關係摘要

### Phase 依賴
- **Setup (Phase 1)**: 無依賴，可立即開始
- **Foundational (Phase 2)**: 依賴 Setup 完成 - 阻擋所有 User Stories
- **User Stories (Phase 3+)**: 全部依賴 Foundational 完成
  - User Stories 可並行執行 (若有團隊資源)
  - 或依優先級順序執行 (P1 → P2)
- **Polish (Phase 7)**: 依賴所有 User Stories 完成

### User Story 依賴
- **US1 (P1)**: Foundational 完成後可開始 - 無其他故事依賴
- **US2 (P2)**: Foundational 完成後可開始 - 可與 US1 整合但應獨立可測
- **US3 (P2)**: Foundational 完成後可開始 - 可與 US1/US2 整合但應獨立可測
- **US4 (P1)**: Foundational 完成後可開始 - 可與其他故事並行

## 並行執行機會
- **Setup**: T002-T006 [P] 可並行
- **Foundational**: T013-T014, T016, T019-T022 [P] 可並行
- **User Stories**: Foundational 完成後，所有 US 可並行
- **Within US**: 模型任務 (T026-T030 [P]) 可並行
- **跨故事**: 不同開發者可同時處理不同 User Story
