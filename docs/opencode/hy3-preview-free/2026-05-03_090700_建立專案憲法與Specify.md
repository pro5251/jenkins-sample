# 建立專案憲法、Specify、Plan 與設置記錄規則

## 問題摘要
用戶根據 `專案用途.md` 的需求，要求協助完成以下任務：
1. 撰寫 SpecKit 的憲法 (憲法.md)
2. 更新 SpecKit 格式的憲法至 `.specify/memory/constitution.md`
3. 根據專案用途撰寫 SpecKit 需要的 Specify (`docs/Specify.md`) 與 plan (`docs/plan.md`)
4. 設置 `AGENTS.md`，要求每次問答後將問題與答案總結記錄在 `docs/opencode/{model_name}/yyyy-MM-dd_HHmmss_問題簡易摘要.md`

## 回答重點
- 憲法包含 5 大核心原則：技術架構、功能需求、開發部署、溝通文件、學習品質
- 採用前後端分離架構 (Vue 3 + .NET 10 + MSSQL)
- 使用繁體中文作為主要溝通語言
- 建立 Jenkins CI/CD 自動化流程
- Specify 文檔包含 4 個 User Stories (P1-P2 優先級)
- Plan 文檔包含技術上下文、憲法檢查、專案結構
- AGENTS.md 已添加問答記錄規則，使用模型名稱 `hy3-preview-free`

1. 讀取 `專案用途.md` 了解專案需求
